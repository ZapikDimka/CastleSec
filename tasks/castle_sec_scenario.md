# 🏰 Castle Sec: Game Design Document (Scenario)

**Назва гри:** Castle Sec  
**Жанр:** Educational CTF / RPG  
**Концепція:** Візуалізація архітектури "Клієнт-Сервер" через метафору середньовічного замку.  
**Кількість рівнів:** 5 Фаз (13 Задач).

---

## 🗺️ ФАЗА 1: Розвідка Околиць (Reconnaissance)
**Локація:** Місто "Клієнтська Долина" (Вулиці, Ринок, Дошка оголошень).  
**Сюжет:** Гравець — просто перехожий. Він нічого не ламає, лише уважно роздивляється навколо (використовує DevTools та URL), збираючи інформацію, яку залишили необачні жителі.

### 1. Задача: "Таємний Напис"
* **Тип:** Client-Side Recon (Source Code Review)
* **Локація:** Дошка Оголошень
* **Легенда:** Наказ короля виглядає звичайним, але повстанці залишили послання для своїх у невидимому чорнилі.
* **Рішення:** Натиснути `F12` (View Source) -> знайти HTML-коментар ``.
* **Docker:** Nginx зі статичним HTML.

### 2. Задача: "Сліпий Архіваріус"
* **Тип:** Information Disclosure (.git)
* **Локація:** Старий Архів
* **Легенда:** Архіваріус забув закрити чорновики історії замку.
* **Рішення:** Знайти папку `/.git/`, викачати репозиторій, знайти видалений прапор у `git log`.
* **Docker:** Веб-сервер з розгорнутим `.git` у public html.

### 3. Задача: "Отруєне Яблуко"
* **Тип:** Reflected XSS (Client-Side)
* **Локація:** Ринок (Пошук товарів)
* **Легенда:** Торговець вигукує все, що ти його попросиш. Якщо попросити його вигукнути заклинання, чи спрацює воно на покупцях?
* **Рішення:** Ввести в пошук `<script>alert(document.cookie)</script>`.
* **Docker:** PHP/Node.js сторінка, що виводить `$_GET['search']` без фільтрації.

### 4. Задача: "Скляний Будинок"
* **Тип:** Misconfiguration / Environment Variables Leak
* **Локація:** Інженерна Майстерня
* **Легенда:** Інженери записали паролі прямо на стінах (у змінних середовища), щоб не забути їх під час будівництва.
* **Рішення:** Знайти сторінку `/status` або `/info`, де виводиться конфіг сервера і змінна `SECRET_KEY`.
* **Docker:** Додаток, що виводить `printenv`.

## ⚔️ ФАЗА 2: Гарнізон та Поштова Станція (Interception & Staging)
**Локація:** Укріплений пункт на виході з міста.  
**Сюжет:** Тут формуються каравани (пакети даних). Гравець починає втручатися в логіку роботи системи: підміняти листи, підбирати ключі до службових входів та обманювати охорону.

### 5. Задача: "Чужі Листи"
* **Тип:** IDOR (Insecure Direct Object Reference)
* **Локація:** Поштова Вежа (Сортувальна)
* **Легенда:** Ти перехопив гінця і бачиш лист №100. Зміни номер на пакунку, щоб прочитати лист Короля.
* **Рішення:** Змінити URL `?id=100` на `?id=1`.
* **Docker:** Скрипт читає файли за ID без перевірки сесії.

### 6. Задача: "Підбір Ключа"
* **Тип:** Brute Force (Weak Credentials)
* **Локація:** Службовий Вхід
* **Легенда:** Старий вартовий погано чує і має дуже простий пароль до дверей складу.
* **Рішення:** Використати список простих паролів (`admin`, `12345`, `password`) для входу.
* **Docker:** HTTP Basic Auth або форма з логіном `admin:12345`.

### 7. Задача: "Подвійне Дно"
* **Тип:** SQL Injection (UNION Based)
* **Локація:** Реєстр Гільдії (Списки караванів)
* **Легенда:** Ти бачиш список легальних торговців. Змусь книгу показати прихований список шпигунів.
* **Рішення:** `?cat=1 UNION SELECT username, password FROM spies`.
* **Docker:** Вразливий SQL-запит до БД з двома таблицями (`merchants`, `spies`).

### 8. Задача: "Вартовий-Телепень"
* **Тип:** SQL Injection (Auth Bypass)
* **Локація:** Головна Брама Гарнізону
* **Легенда:** Вартовий пускає тих, хто є у списку, АБО якщо діє "магічне правило" істини.
* **Рішення:** Логін: `' OR '1'='1`. Пароль: будь-який.
* **Docker:** Вразливий запит авторизації. Успіх відкриває доступ далі.

## 🐫 ФАЗА 3: Караван до Брами (Server-Side Web Exploits)
**Локація:** Шлях до Замку та взаємодія з його службами.  
**Сюжет:** Гравець пройшов первинну авторизацію. Тепер він має доступ до "публічних" сервісів замку (Бібліотека, Сигналізація) і намагається змусити їх працювати проти власників.

### 9. Задача: "Бібліотечні Схованки"
* **Тип:** Path Traversal / LFI
* **Локація:** Королівська Бібліотека
* **Легенда:** Попроси бібліотекаря принести документ не з публічної полиці, а з секретного підвалу.
* **Рішення:** `?book=../../../../etc/passwd` (або `flag.txt`).
* **Docker:** Скрипт читає файл за шляхом з URL без санітизації (`../`).

### 10. Задача: "Луна в Колодязі"
* **Тип:** Command Injection (Simple)
* **Локація:** Сигнальна Вежа (Ping tool)
* **Легенда:** Вартовий на вежі повторює твою команду в ріг. Додай до наказу свою власну команду.
* **Рішення:** `8.8.8.8; ls -la`.
* **Docker:** `os.system("ping " + input)`.

## 💎 ФАЗА 4: Скарбниця та Тронна Зала (Post-Exploitation)
**Локація:** Всередині Замку.  
**Сюжет:** Гра "ламається". Гравець отримує **Web Shell** (чорний термінал). Тепер він фізично знаходиться на сервері. Мета — підвищити права до Короля (Root).

### 11. Задача: "Забутий Прохід"
* **Тип:** RCE (File Upload)
* **Локація:** Галерея: Зміна Герба
* **Легенда:** Завантаж "сувій заклинання" (PHP-шелл) замість картинки герба.
* **Рішення:** Завантажити `shell.php`, відкрити його через браузер.
* **Ефект:** Інтерфейс змінюється на термінал. Ти — юзер `www-data`.
* **Docker:** Uploads папка з правами виконання скриптів.

### 12. Задача: "Механізм Годинника"
* **Тип:** Linux Privilege Escalation (Cron)
* **Локація:** Годинникова Вежа (Серце сервера)
* **Легенда:** Ти — слуга. Знайди механізм, який заводить сам Король (Root), і підклади туди свій наказ.
* **Рішення:** Знайти скрипт у Cron, що доступний для запису. Дописати команду читання Root-прапора.
* **Ефект:** Ти отримуєш `flag{ROOT_ACCESS}`.
* **Сюжетний твіст:** *Система оголошує тривогу і блокує гравця.*

## ⛓️ ФАЗА 5: Епілог — В'язниця (Container Breakout)
**Локація:** Темниця.  
**Сюжет:** Бонусний рівень. Гравець думав, що переміг, але опинився в ізоляторі (Docker-контейнері). Треба втекти в реальний світ.

### 13. Задача: "Дірява Стіна"
* **Тип:** Docker Socket Escape
* **Локація:** Камера Одиночка (Ізольований контейнер)
* **Легенда:** Ти думав, що ти Король, але ти лише в'язень у коробці. Знайди дірку в стіні (Socket) і вийди на волю.
* **Рішення:**
    1. `ls -la /var/run/docker.sock`
    2. `docker run -it -v /:/host alpine chroot /host`
    3. `cat /root/REAL_FLAG.txt`
* **Docker:** Контейнер з прокинутим сокетом (`-v /var/run/docker.sock:/var/run/docker.sock`).
* **Фінал:** "ESCAPED TO HOST". Справжній кінець гри.
