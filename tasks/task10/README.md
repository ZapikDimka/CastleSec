# Task10 — Луна в Колодязі (симуляція Command Injection)

Це навчальна задача у стилі CTF. Важливо: **бекенд НЕ виконує реальні системні команди**. Замість цього використовується безпечний «міні-інтерпретатор», щоб показати ідею command injection без ризику.

Ускладнення: флаг захований у іншій віртуальній директорії. Щоб дістати його, треба виконати **композитну** команду (приклад: перейти `cd ..`, зайти в іншу папку, тоді `cat` флаг).

## Запуск
```bash
cd task10
docker compose up --build
```

Потім відкрий у браузері:
- http://localhost:8010

## Порти
- Зовні: `8010`
- Всередині контейнера: `8080`

## ENV
- `TASK10_PASSWORD` — пароль/флаг, який треба здобути та ввести у форму.

## Доступні псевдокоманди
`help`, `ping`, `pwd`, `cd`, `ls`, `cat`, `date`, `whoami`, `echo`.
