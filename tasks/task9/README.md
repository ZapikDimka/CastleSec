# CastleSec — T9 “Бібліотечні Схованки” (Path Traversal)

## Мета
Дістатися до королівського файла (флага) за межами Скрипторію.

## Баланс складності
- Гравець бачить **і лор, і директорії**, але **не всюди**.
- Скрипторій (BASE_DIR) — відкритий: можна переглядати полиці/сувої.
- Цитадель (KEEP_DIR) — також відкрита: якщо ти правильно “вийшов нагору”, можна побачити кімнати й знайти королівський файл.
- Проміжні крила (наприклад, рівні Вежі) можуть бути запечатані й не показують перелік.

## Підказка
При першому використанні `..` сервер дає одноразовий натяк (cookie).

## Запуск
```bash
docker compose up --build
```
http://localhost:18009


## Variant A (баланс)
- У Скрипторії показуються і файли, і директорії.
- У Цитаделі/інших крилах listing показує **лише директорії (кімнати)**.
- Файли в таких крилах не відображаються: потрібна точна назва (її дає сувій `seal_registry.txt`).


## Довший шлях виконання
- У Keep додано більше кімнат і кілька рівнів королівського маршруту.
- Маршрут зберігає ту ж складність: у Keep видно лише кімнати, а файл відкривається по точній назві.
- Флаг: /data/keep/royal_quarter/inner_palace/antechamber/seal_vault/royal_sigil.txt
